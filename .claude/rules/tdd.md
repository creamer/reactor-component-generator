# TDD Rule

> **경고: 이 규칙은 Rigid다. 상황에 맞게 변형하지 마라.** 단계를 건너뛰거나 순서를 바꾸거나 "이번만 예외"를 만들지 않는다.

## 1. 적용 기준

### TDD를 반드시 적용하는 대상

- **비즈니스 로직**: 조건 분기, 계산, 상태 전이, 검증 규칙
- **API**: 라우트 핸들러, 요청/응답 처리, 에러 매핑
- **유틸 함수**: 파싱, 정규화, 변환 등 순수 함수
- **버그 수정**: 먼저 버그를 재현하는 실패 테스트를 작성한 뒤 고친다

### TDD가 불필요한 대상

- **타입 정의**: `type`, `interface`만 있는 파일
- **설정 파일**: `vite.config.ts`, `tsconfig.json`, `eslint.config.js` 등
- **순수 UI**: 로직 없이 마크업과 스타일만 있는 컴포넌트
- **SQL**: 스키마, 마이그레이션, 쿼리 정의

경계가 애매하면(로직이 섞인 UI 등) **로직 부분을 분리해 그 부분에 TDD를 적용한다.**

## 2. RED-GREEN-REFACTOR 사이클

### RED: 실패하는 테스트를 먼저 쓴다

- **하나의 동작 = 하나의 테스트.** 한 테스트에 여러 동작을 담지 않는다.
- 테스트 이름은 기대하는 동작을 서술한다.
- **반드시 실행해서 실패를 확인한다.** 실행하지 않은 RED는 RED가 아니다.
- **실패 이유가 "기능 미구현"이어야 한다.** 문법 오류, import 오류, 잘못된 셋업으로 실패했다면 테스트를 고쳐 올바른 이유로 실패하게 만든다.

### GREEN: 통과시키는 최소한의 코드만 쓴다

- 테스트를 통과시키는 **최소한의 코드**만 작성한다. **YAGNI**: 지금 테스트가 요구하지 않는 분기, 옵션, 확장 포인트를 넣지 않는다.
- **신규 테스트와 기존 테스트가 모두 통과하는지** 실행해서 확인한다.

### REFACTOR: green을 유지하며 정리한다

- 중복 제거, 이름 개선, 헬퍼 추출만 한다.
- **모든 테스트가 green인 상태를 유지한다.** 수정할 때마다 실행한다.
- **새 동작을 추가하지 않는다.** 새 동작이 필요하면 RED로 돌아간다.

### 반복

- 다음 동작에 대한 **RED로 돌아간다.** 요구사항이 끝날 때까지 한 사이클에 한 동작씩 진행한다.

## 3. 삭제 강제 규칙

- **테스트 전에 프로덕션 코드를 먼저 작성했다면 그 코드를 삭제하고 RED부터 다시 시작한다.**
- **"참고용"으로 남기는 것도 금지한다.** 주석 처리, 임시 파일, 별도 브랜치 보관, 복사해 두기 모두 포함한다. 남겨 두면 테스트가 코드를 따라 쓰이게 되어 TDD가 아니게 된다.

## 4. 변명 차단표

| 변명 | 반론 |
| --- | --- |
| "너무 단순해서 테스트가 필요 없다" | 단순한 코드는 테스트도 한 줄이다. 단순해 보이는 코드가 가장 자주 깨지고, 테스트 없이는 나중에 단순하다는 사실을 증명할 수 없다. |
| "나중에 추가하겠다" | 나중에 쓴 테스트는 이미 있는 구현에 맞춰 쓰게 되고 곧바로 통과한다. 통과하는 테스트는 아무것도 증명하지 않는다. 나중은 오지 않는다. |
| "시간이 없다" | 테스트 없는 코드의 디버깅과 회귀 수정이 더 오래 걸린다. 시간이 없을수록 되돌아오는 비용이 큰 방식을 쓸 수 없다. |
| "삭제하면 낭비다" | 이미 쓴 시간은 매몰 비용이다. 테스트로 검증되지 않은 코드를 유지하는 것이 더 큰 낭비다. 테스트를 먼저 쓰면 다시 쓰는 데 오래 걸리지 않는다. |
| "프로토타입이다" | 프로토타입은 버려질 때만 프로토타입이다. 버릴 게 아니라면 정식 코드이고, 버릴 것이면 대상이 아니라고 사용자가 명시해야 한다. 스스로 판단해 면제하지 않는다. |

## 5. 프로젝트별 규칙 우선

- 프로젝트의 `CLAUDE.md` 또는 `AGENTS.md`에 TDD 규칙이 있으면 **그 규칙을 우선한다.**
- **이 파일은 기본값(fallback)이다.** 프로젝트 규칙이 다루지 않는 부분에만 적용한다.
- 우선권은 프로젝트 규칙에만 있다. 이 파일을 근거로 한 임의 완화는 허용되지 않는다.
